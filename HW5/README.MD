## 📘 Краткое описание

Реализована модель банковской системы с поддержкой разных типов счетов, историей операций, визуализацией данных и обработкой «грязных» файлов.  

Программа состоит из трёх классов:
- `Account` — базовый класс, реализует общие методы и валидацию;
- `SavingsAccount` — сберегательный счёт с ограничением снятия и начислением процентов;
- `CheckingAccount` — расчётный счёт со стандартными операциями.

## ⚙️ Основные классы

### 🧱 `Account`
Базовый класс, содержащий общую функциональность:
- автоматическая генерация номера счёта (`ACC-XXXX`);
- проверка имени владельца (`Имя Фамилия`);
- методы:
  - `deposit(amount)`
  - `withdraw(amount)`
  - `get_balance()`
  - `get_history()`
  - `print_history()`
  - `analyze_history()`
  - `plot_history()`
  - `clean_history(raw_records)`
  - `load_history_from_file(filepath)`

---

### 💰 `SavingsAccount`
- Ограничение снятия — не более 50 % от текущего баланса.  
- Метод `apply_interest(rate)` начисляет проценты.  
- `_apply_clean_operation()` учитывает проценты и лимит снятия при загрузке из файлов.  

---

### 💳 `CheckingAccount`
- Разрешены операции `deposit` и `withdraw`.  
- Снятие средств возможно только при достаточном балансе.  
- `_apply_clean_operation()` корректно фиксирует ошибки и обновляет баланс при загрузке из файлов.
